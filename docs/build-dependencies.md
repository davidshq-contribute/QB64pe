## Windows

### Required Dependencies

#### MinGW-w64 (LLVM MinGW)
- **Purpose**: C++ compiler toolchain
- **Installation**: Automatically downloaded and installed by `setup_mingw.cmd`
- **Location**: `internal/c/c_compiler/`
- **Source**: [LLVM MinGW releases](https://github.com/mstorsjo/llvm-mingw/releases)
- **Components Included**:
  - `gcc.exe` / `c++.exe` - C++ compiler
  - `mingw32-make.exe` - Build system
  - `ar.exe` - Archive utility
  - `objcopy.exe` - Object file utility
  - `windres.exe` - Resource compiler
  - Standard C/C++ runtime libraries

#### Make Utility
- **Purpose**: Build automation
- **Installation**: Included with MinGW-w64 as `mingw32-make.exe`
- **Location**: `internal/c/c_compiler/bin/mingw32-make.exe`

#### Command Prompt Extensions
- **Purpose**: Required for setup scripts to function
- **Note**: Standard Windows Command Prompt (cmd.exe) has these enabled by default
- **Issue**: PowerShell or restricted environments may not have all extensions

### Optional Dependencies

#### PowerShell
- **Purpose**: Architecture detection (32-bit vs 64-bit)
- **Installation**: Pre-installed on Windows 7 and later
- **Note**: If unavailable, setup defaults to 64-bit MinGW

### Installation Instructions

1. **Automatic Installation** (Recommended):
   ```cmd
   setup_win.cmd
   ```
   This script will:
   - Detect your system architecture (32-bit or 64-bit)
   - Download and extract MinGW-w64 if not present
   - Build QB64-PE

2. **Manual MinGW Setup**:
   ```cmd
   setup_mingw.cmd [32|64]
   ```
   - Omit argument for automatic detection
   - Use `32` to force 32-bit MinGW on 64-bit systems
   - Use `64` to force 64-bit MinGW

3. **Manual Build** (if MinGW is already installed):
   ```cmd
   internal\c\c_compiler\bin\mingw32-make.exe OS=win BUILD_QB64=y
   ```

### System Requirements

- **Windows Version**: Windows 7 or later
- **Disk Space**: At least 500MB free space (for MinGW download and build)
- **Network**: Internet connection required for initial MinGW download
- **Permissions**: Write permissions in the QB64-PE directory

### Troubleshooting

- **"Command Prompt extensions not available"**: Run in standard `cmd.exe`, not PowerShell
- **"C++ compiler not found"**: Verify MinGW setup completed; check antivirus hasn't quarantined files
- **"Make utility not found"**: Ensure MinGW installation is complete
- **Antivirus blocking**: Whitelist the `qb64pe` folder in your antivirus software

## Linux

### Required Dependencies

#### Build Tools

##### GNU C++ Compiler (g++)
- **Package Names**:
  - Debian/Ubuntu: `build-essential` (includes g++)
  - Fedora/RHEL: `gcc-c++`
  - Arch: `gcc`
  - Void: `gcc`
- **Purpose**: Compiles C++ source code generated by QB64-PE
- **Alternative**: `gcc` with C++ support

##### Make Utility
- **Package Names**:
  - Debian/Ubuntu: `build-essential` (includes make)
  - Fedora/RHEL: `make`
  - Arch: `make`
  - Void: `make`
- **Purpose**: Build automation and dependency management

#### Graphics Libraries

##### OpenGL Development Libraries
- **Package Names**:
  - Debian/Ubuntu: `mesa-common-dev`, `libglu1-mesa-dev`
  - Fedora/RHEL: `mesa-libGLU-devel`
  - Arch: `glu` (included in base)
  - Void: `glu-devel`
- **Purpose**: OpenGL rendering support
- **Libraries Linked**: `-lGL -lGLU`

##### X11 Utilities
- **Package Names**:
  - Debian/Ubuntu: `x11-utils`
  - Fedora/RHEL: Usually pre-installed
  - Arch: `xorg-xdpyinfo` (optional)
  - Void: Usually pre-installed
- **Purpose**: X11 windowing system support
- **Libraries Linked**: `-lX11 -lxcb`

#### Audio Libraries

##### ALSA Development Libraries
- **Package Names**:
  - Debian/Ubuntu: `libasound2-dev`
  - Fedora/RHEL: `alsa-lib-devel`
  - Arch: `alsa-lib` (development headers included)
  - Void: `alsa-lib-devel`
- **Purpose**: Audio output support

#### Network Libraries

##### libcurl Development Libraries
- **Package Names**:
  - Debian/Ubuntu: `libcurl4-openssl-dev`
  - Fedora/RHEL: `libcurl-devel`
  - Arch: `curl`
  - Void: `libcurl-devel`
- **Purpose**: HTTP client functionality (`_OPENCLIENT()`)

#### Image Libraries

##### libpng Development Libraries
- **Package Names**:
  - Debian/Ubuntu: `libpng-dev`
  - Fedora/RHEL: `libpng-devel`
  - Arch: `libpng`
  - Void: `libpng-devel`
- **Purpose**: PNG image format support

#### Compression Libraries

##### zlib
- **Package Names**:
  - Debian/Ubuntu: Usually included with `build-essential`
  - Fedora/RHEL: Usually pre-installed
  - Arch: `zlib`
  - Void: Usually pre-installed
- **Purpose**: Compression support (`_INFLATE$()`, `_DEFLATE$()`)

### Installation Instructions

#### Automatic Installation (Recommended)

Run the setup script, which will detect your distribution and install required packages:

```bash
./setup_lnx.sh
```

**Supported Distributions**:
- Debian/Ubuntu/Linux Mint/Zorin (apt-get)
- Fedora/RHEL/CentOS (dnf/yum)
- Arch Linux (pacman)
- Void Linux (xbps-install)

#### Manual Installation by Distribution

##### Debian/Ubuntu/Linux Mint/Zorin
```bash
sudo apt-get update
sudo apt-get install build-essential x11-utils mesa-common-dev libglu1-mesa-dev libasound2-dev libpng-dev libcurl4-openssl-dev
```

##### Fedora/RHEL/CentOS
```bash
# For Fedora 22+ (dnf)
sudo dnf install gcc-c++ make mesa-libGLU-devel alsa-lib-devel libpng-devel libcurl-devel

# For older versions (yum)
sudo yum install gcc-c++ make mesa-libGLU-devel alsa-lib-devel libpng-devel libcurl-devel
```

##### Arch Linux
```bash
sudo pacman -S gcc make zlib curl
```

##### Void Linux
```bash
sudo xbps-install -Sy gcc make glu-devel libpng-devel alsa-lib-devel libcurl-devel
```

#### Manual Build

If all dependencies are installed:

```bash
make OS=lnx BUILD_QB64=y
```

### System Requirements

- **Linux Distribution**: Any modern distribution with package manager support
- **Architecture**: x86_64 or x86 (32-bit)
- **Disk Space**: At least 500MB free space
- **Permissions**: Regular user account (script will prompt for sudo when needed)

### Troubleshooting

- **"Unable to detect distro"**: Install packages manually using your distribution's package manager
- **"Make utility not found"**: Install `make` package for your distribution
- **"C++ compiler not found"**: Install `g++` or `gcc-c++` package
- **Missing library errors**: Check that all development packages (with `-dev` or `-devel` suffix) are installed
- **"Running as root"**: Do not run setup script as root; it will prompt for sudo when needed

## macOS

### Required Dependencies

#### Xcode Command Line Tools
- **Purpose**: Provides C++ compiler (clang++), make, and other build tools
- **Installation**: 
  ```bash
  xcode-select --install
  ```
- **Components Included**:
  - `clang++` - C++ compiler
  - `make` - Build system
  - Standard C/C++ runtime libraries
  - System frameworks (OpenGL, Cocoa, etc.)

### System Frameworks (Pre-installed)

The following frameworks are provided by macOS and do not require separate installation:

- **OpenGL** - Graphics rendering
- **GLUT** - Window management (system implementation, not FreeGLUT)
- **Cocoa** - macOS application framework
- **IOKit** - Hardware interface
- **ApplicationServices** - Application services
- **CoreFoundation** - Core Foundation framework

### Installation Instructions

1. **Install Xcode Command Line Tools**:
   ```bash
   xcode-select --install
   ```
   This opens a dialog window. Follow the installation prompts.

2. **Run Setup Script**:
   ```bash
   ./setup_osx.command
   ```

3. **Manual Build** (if tools are installed):
   ```bash
   make OS=osx BUILD_QB64=y
   ```

### System Requirements

- **macOS Version**: macOS Catalina (10.15) or later
- **Disk Space**: At least 500MB free space
- **Architecture**: Intel (x86_64) or Apple Silicon (ARM64)

### Troubleshooting

- **"C++ compiler (clang++) not found"**: Run `xcode-select --install` to install Command Line Tools
- **"Make utility not found"**: Ensure Command Line Tools are properly installed
- **Build fails**: Verify Command Line Tools installation with `xcode-select --reset`
- **"Command Line Tools may already be installed"**: Try `xcode-select --reset` to reconfigure

## Third-Party Libraries

QB64-PE includes many third-party libraries that are statically linked into compiled programs. These libraries are **already included** in the QB64-PE source code and do not need to be installed separately for building.

### Libraries Included in Source

The following libraries are bundled in `internal/c/parts/` and compiled as part of the build process:

#### Graphics & Display
- **FreeGLUT** (Windows/Linux) - Window management
- **System GLUT** (macOS) - Window management (system provided)

#### Image Support
- **stb_image** - Image loading (multiple formats)
- **nanosvg** - SVG support
- **dr_pcx** - PCX format support
- **QOI** - QOI format support
- **stb_image_write** - Image writing
- **HQx, MMPX, Super-xBR** - Image upscaling algorithms

#### Font Support
- **FreeType** - Font rendering

#### Audio Support
- **miniaudio** - Audio playback
- **foo_midi, libmidi** - MIDI support
- **HivelyTracker** - Music format support
- **libxmp-lite** - Module format support
- **primesynth** - Sound synthesis
- **QOA** - Audio format support
- **RADv2** - Audio format support
- **stb_vorbis** - Ogg Vorbis support
- **TinySoundFont** - SoundFont support
- **ymfmidi** - MIDI support

#### Network Support
- **libcurl** - HTTP client functionality

#### Data Processing
- **miniz** - Compression (zlib-compatible)
- **MODP_B64** - Base64 encoding/decoding

#### Input Support
- **libstem Gamepad** - Game controller support

#### GUI Support
- **tiny file dialogs** - File dialogs and alerts

#### Clipboard Support
- **Clip Library** - Clipboard image support

### License Information

All third-party libraries have their licenses documented in the `licenses/` directory. See `licenses/README.md` for detailed licensing information.

**Important**: When distributing programs compiled with QB64-PE, you must respect the licenses of any third-party libraries that are compiled into your program. Most libraries use permissive licenses (MIT, Public Domain, etc.), but some (like libstdc++ on Windows) use GPLv3 with exceptions.

## Build Process Overview

1. **Setup Phase**: Install platform-specific dependencies (MinGW on Windows, packages on Linux, Command Line Tools on macOS)
2. **Compilation Phase**: QB64-PE compiles `.bas` files to C++ code
3. **Linking Phase**: C++ code is compiled and linked with required libraries
4. **Output**: Native executable for the target platform

### Build Commands

#### Windows
```cmd
setup_win.cmd                    # Full setup and build
internal\c\c_compiler\bin\mingw32-make.exe OS=win BUILD_QB64=y  # Manual build
```

#### Linux
```bash
./setup_lnx.sh                  # Full setup and build
make OS=lnx BUILD_QB64=y        # Manual build
```

#### macOS
```bash
./setup_osx.command              # Full setup and build
make OS=osx BUILD_QB64=y        # Manual build
```
