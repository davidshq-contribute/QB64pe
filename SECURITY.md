# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in QB64 Phoenix Edition, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities
2. Email the maintainers directly or use GitHub's private vulnerability reporting feature
3. Include a detailed description of the vulnerability and steps to reproduce

We will acknowledge receipt within 48 hours and work to address the issue promptly.

## Scope

Security issues we're interested in:

- Buffer overflows in the compiler or runtime
- Code injection vulnerabilities
- Memory corruption bugs
- Vulnerabilities in generated executables

## Out of Scope

- Bugs in user-written QB64 programs
- Denial of service through malformed source files (compiler crashes are bugs, not security issues)
- Issues in third-party libraries (report to upstream)
